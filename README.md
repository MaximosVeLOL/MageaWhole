This here contains all of Magea, which stands for:
M	A	G	E	A
Make	Another	Game	Engine	Again

I have made so many game engines, which all have failed due to many issues, but now,
hopefully, this will be the last one.

Here are the explanations for all the projects:



|Core|This holds all core components (rendering, audio, common things, ect.). Made seperate for organization and other projects.|
|-|-|
|MGUI|This is a GUI library that is also made seperate for organization and other projects. This also includes the ability to have textured widgets or colored rects.|
|Magea|This is the game engine that uses all projects. This contains useful 2D game engine stuff such|
|tools|The developer tools that use Magea's developer API.|
|Game|This is a game template that uses other projects in the list for game creation. This is then used later by Magea.|
